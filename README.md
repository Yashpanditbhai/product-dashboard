# 🧭 Product Dashboard

A simple and modern **Product Dashboard** built with **Next.js, TypeScript, and Tailwind CSS**.  
It includes authentication using Context API and a clean dashboard UI to manage and view products.

---

## 🚀 Features

- 🔐 Login system (persistent across sessions)
- 🧱 Protected routes using global context
- 🎨 Styled with Tailwind CSS
- ⚡ Built on Next.js (App Router)
- 🧰 TypeScript for type safety

---

## 🧩 Tech Stack

- **Frontend:** Next.js 14+, React 18, TypeScript
- **Styling:** Tailwind CSS
- **State Management:** React Context API
- **Routing:** Next.js App Router
